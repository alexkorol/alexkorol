- **[WIZARD](https://github.com/alexkorol/WIZARD)** - interactive game-UI experiments. Flagship: a WebGL2 health/mana orb engine where one fragment shader draws the liquids, built from six AI-generated art plates, shipped as a single self-contained HTML file (live demo linked in the repo).
