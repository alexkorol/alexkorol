### Prosody — LLM lyric generation pipeline

Multi-stage fine-tuning system for creative text generation: LoRA/QLoRA fine-tuning, custom reward models, GRPO optimization. The public components:

- **[prosody-judge](https://github.com/alexkorol/prosody-judge)** — LLM-as-a-judge evaluation layer. Scores both reasoning traces and final lyrics across 8 rubric dimensions, with 3-run self-consistency, consensus flagging, and structured JSON output used as GRPO reward signal.
- **[songcraft-rag](https://github.com/alexkorol/songcraft-rag)** — knowledge-retrieval layer. 45-document, 2,376-page songwriting & music theory corpus indexed into 7,370 chunks; local ONNX embeddings, ChromaDB, cited answers via CLI and FastAPI.

### Tools

- **[repo2GPT](https://github.com/alexkorol/repo2GPT)** — turns any repository into an LLM-ready repo map plus consolidated code bundle. Language-aware summaries for Python, JS/TS, Go, Rust, Ruby, and PHP.
- **[pixel-perfecter](https://github.com/alexkorol/pixel-perfecter)** — reconstructs clean, grid-aligned sprites from diffusion-generated pixel art. Grid estimation and color-cell reconstruction core, PySide6 GUI, batch CLI.
